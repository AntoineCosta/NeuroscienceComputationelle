How the network is wired
The network has four populations, plus regular Python code at the edges (a brain on the input side, a body/world/sensor loop on the output side).

1. CPG: the fixed rhythm (2 LIF neurons)
A is a pacemaker: a constant drive makes it fire exactly every 500 ms, starting at t = 0.
B is a relay: one synapse from A, delayed by half a period, makes it fire 250 ms after A.
So there's one spike per half-cycle, alternating A and B. Each leg's phase is (rank + side) mod 2. That splits the legs into two tripods: A-legs are in stance while B-legs swing, then they switch.
2. Leg motor neurons (per leg: R, D, N × F, N × B)
They're LIF neurons with τ = 20 ms. Their thresholds are evenly spaced, θ_k = (k + ½)·u, so an input of m·u reaches exactly the m lowest thresholds.

Neuron	Excited by	EPSP	Braked by
D (lower)	its stance CPG neuron	N·u	nothing: it lowers the foot at every stance onset
R (raise)	the other CPG neuron, plus a 10 ms lift delay	2N·u	I-Fwd and I-Rev of its side
F, B	both CPG neurons	N·u	the direction and steer intermediates
Without inhibition, all N F neurons and all N B neurons would fire. The number that fire is the stroke size: N minus the inhibition, lowest thresholds first. Inhibition is released at the CPG spike and arrives just before the excitation, which lands EXC_DELAY (2 ms) later.

3. Intermediates: 6 graded inhibitory neurons
They don't spike. Each one has an activity level = clip(brain + gate·sensor, 0, 1) that means "how much to brake".

At each CPG spike, a trigger synapse tells them which tripod is now in stance. One step later each one releases an inhibition of level·N onto its own side:

Intermediate	Legs in stance	Legs in swing	Also
I-Fwd-X	brakes F (forward push)	brakes B (return)	R
I-Rev-X	brakes B (reverse push)	brakes F (return)	R
I-Steer-X	brakes F and B	brakes F and B	–
So walking forward at speed s means I-Fwd = 1 − s and I-Rev = 1. That gives s·N F neurons in stance (the push) and s·N B neurons in swing (the return, which mirrors the push).

4. Sensors: 6 graded neurons
Activity: each one turns a distance into near, ramping 0 → 1 from its range down to 5 cm. The front and rear sensors also have close, which ramps 0 → 1 below 0.2 m and drives the back-off.
Output: a summed synapse into the intermediates' sensor input. Most weights are positive (brake). The back-off weights are negative and inhibit the opposite direction's intermediate, which releases walking away from the obstacle (disinhibition).
Sensor	Effect
FL, FR (front)	brake forward (each gives half); turn away using FL − FR; back-off → walk backward
RL, RR (rear)	brake reverse; back-off → walk forward
SL, SR (sides)	turn away using SL − SR (centres in corridors)
What the regular code does
The code only touches the network in three ways: it writes neuron variables (brain, gate, distance), it reads spikes (SpikeMonitor), and it runs as Brian network_operation hooks called at fixed times inside the simulation loop.

Code	When	Reads	Writes / does
Keyboard / Gamepad / timeline	on request	keys, stick, script	(speed, steer)
Brain (brain.py)	start of each half-cycle, just before the CPG spike	(speed, steer)	brain of the 6 intermediates (stop pattern by default), and gate = 1 only while walking
Robot.odometry (robot.py)	every 10 ms; acts once a half-cycle's spikes are in (about 13 ms after the CPG spike)	motor spikes of that half-cycle	Body: F − B of the legs in stance → body push (differential drive); R/D → feet up/down
Sensors.update (sensors.py)	every 10 ms	current pose, World	ray casting → distance of the 6 sensor neurons
Display (manual.py)	20 fps	pose, feet, rays	drawing and real-time pacing
The closed loop: command → brain → intermediates → motor spikes → body pose → world → sensor neurons → intermediates.

The brain decides what to do. The CPG decides when. The intermediates turn graded commands into how many motor neurons fire. The sensors can override the brain only through those same intermediates.

One half-cycle in time
Time after the CPG spike	Event
0 (same step, just before)	the brain latches the command, brain and gate are set
0	CPG spike; the intermediates learn which tripod is in stance
+0.5 ms	the intermediates release inhibition (level·N)
+2 ms	CPG excitation reaches F, B and D; the unbraked ones fire (push, return, foot down)
+12 ms	R fires: the swinging tripod lifts, after the other has touched down
~+13 ms	odometry counts the spikes; the body moves by that push over the half-cycle
0 to 250 ms	sensors update every 10 ms; their effect applies at the next CPG spike
